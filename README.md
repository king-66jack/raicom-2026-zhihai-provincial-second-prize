## 结果

该方案在平台的验证集中取得的分数：**0.9544**。


## 数据处理

官方提供的数据集规模：五千张图片左右，该数据集存在数据分布不均衡（某些类的数据很多，某些类的数据很少）、数据脏（我们团队从每一类中抽样100张进行观察，发现少量图片存在标签错误、数据集中掺杂了AI生成图片）。如果不对数据进行处理，只是简单的划分数据集进行训练，最终的F1大概在0.91（一个简单的训练脚本）。所以解决数据不均衡的问题在本次比赛比较重要。一个好的方法是尝试扩充数据，希望在模型能够在增强的数据上训练，得到更好的表征能力。在我们的实验中 F1 提升到了0.93。效果不错

> [!TIP]
>
> 外部数据集很大概率和官方提供的数据集不是同一个域（官方保证训练集、验证集、测试集是同一个域）。这意味着完全相信外部数据集是错误行为（团队在早期测试中盲目的加入外部数据，导致F1掉到了0.78，很明显模型被带偏了）。

这引出来了什么是好的外部数据。一个可能的答案如下：

- 第一步：分析外部数据和官方数据差异。如：图片尺寸分布、分辨率、通道数、采集设备、场景等。除了一些难以改变的因素（场景、分辨率）外，剩下的可以尝试去修改，如尺寸（在这里我推荐采用居中裁剪）。
- 第二步：利用由官方数据训练而成的模型对第一步得到的图片进行推理，从正确和错误的图片各自等比例的抽取图片作为候选外部数据。

## 预训练模型选型

ConvNeXtV2 系列模型、Swin-Base 模型、 EVA02-Base模型。这三个模型的架构是不一致，ConvNeXtV2 是 CNN 架构、Swin-Base是 VIT 架构 、EVA02-Base是 VIT 与 CNN 的混合架构。我们认为不同架构的的模型在看同一张图片的时会学习到不同的特征。

> [!TIP]
>
> 模型一般要选择使用 ImageNet  预训练模型。

## 训练方法

> 该章节主要说明在 **train** 采取的一些尝试。

### 数据增强

在图像分类领域中存在着很多的技术增强手段如：几何变换、颜色变换、遮挡增强、混合增强和自动增强等。常见方法包括随机裁剪与缩放（RandomResizedCrop）、水平/垂直翻转（HorizontalFlip / VerticalFlip）、旋转（Rotation）、颜色抖动（ColorJitter）、高斯模糊（GaussianBlur）、随机擦除或粗粒度遮挡（RandomErasing / CoarseDropout）、混合样本增强（Mixup / CutMix）以及自动增强策略（AutoAugment / RandAugment）等

> **该任务（天气分类）依赖亮度、颜色、天空/地面比例和全局信息，因此增强要保守**

训练阶段采取的增强： RandomResizedCrop、HorizontalFlip、 GaussianBlur、 CoarseDropout。

明确禁用：Mixup 、CutMix 、 RandAugment 、 ColorJitter 、 rotation 、 vertical flip。

### 多尺度特征融合

> 在本次比赛中，该方法主要针对ConvNeXtV2 系列模型。在图像分类中人们一般使用其 stage4 的输出作为分类头的输入。这自然而然由一种信念：多尺度的特征融合是否有利于分类头的训练。

在我们的实验中，最好的是stage3 、 stage4这两层的融合，采取的融合措施是：门控网络学习（以stage4为主按需加入stage3的特征），最终该方法相较于老方法在 F1 上大概提升了0.015。

### 蒸馏

我们尝试过蒸馏，该方法最初的设想是：基于响应的蒸馏。

我们先使用参数更大的预训练模型在官方数据集上进行微调以适应官方的数据分布。

小模型主要学习的是：一部分跟真实标签学习，另一部分跟教师模型学习。其公式为：*L_total = α · L_hard + (1 − α) · T² · L_KD*

但是效果不尽如意，在不同的超参数下，蒸馏模型并没有在 F1 上变现出很大的优势。最好不过才增加了0.003，完全不值得。

> 为了进一步判断教师有没有真正提供额外知识，我们把每个样本上的预测情况分为四类：
>
> · A：教师和学生都预测正确；
>
> · B：教师正确、学生错误，说明教师有机会纠正学生；
>
> · C：学生正确、教师错误，说明教师可能把学生带偏；
>
> · D：教师和学生都错误，说明这个样本对双方都比较困难。
>
> 这里最关键的是 B 和 C 的差值。教师模型 能纠正 B 张学生错误样本，但同时也会在 C 张学生原本正确的样本上出错，净纠正( B - C )数字小，意味着教师并没有真正提供额外知识。

### train阶段

对于单模型我们采取两阶段方案

官方数据先单独切：
official_train 80%
official_val   20%

Stage-1：
训练 = official_train + extra_train
验证 = official_val

Stage-2：
加载 Stage-1 best 模型
训练 = official_train
验证 = official_val

> 这样还是对外部数据的不自信，怕改变分布的一致性。

###  参数选择

总的原则是尽量不使用大的学习率改变预训练模型的能力，其他的参数则尝试空间搜索去寻找，在这里我们知道有一种自动化的方法去寻找，碍于时间的原因我们没有使用。
